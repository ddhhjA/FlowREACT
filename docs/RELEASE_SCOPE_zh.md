# 发布范围与来源

本仓库仅发布面向 REACT2025 的源码，包括 FlowREACT V41 模型、3DMM 到情绪标签的转换器、Hydra 配置、训练与评估代码、分析工具及相关测试。不包含生成的输出、REACT2024 数据适配代码或审稿材料。

仓库中的 `LICENSE` 是 REACT2025 基线代码附带的许可声明。FaceVerse、PIRender、挑战赛数据集及其训练资源适用各自的使用条款，均未打包。使用可选渲染功能或运行数据加载器前，请从相应项目获取所需资源。发布此目录时，不应加入数据集压缩包、人脸视频、checkpoint 或其他受限制的资源。

本地原始工作目录还包含一个从现有 FlowREACT checkpoint 初始化、加入时序 GAN 的**微调**脚本。该脚本并未实现从零训练、以纯 GAN 损失替换原目标的实验，因此本次发布不将其作为论文所报告 GAN 对比实验的复现代码。如需从本仓库复现该实验，应另行加入经过核实的纯 GAN 训练实现。

源码配置的 REACT2025 默认窗口大小为 8 帧。checkpoint 的训练设置与评估设置应保持一致；本次源码整理不改变训练行为或实验结果。

README 中的命令以及源码、配置文件链接已进行静态检查。完整的 CUDA 训练和指标评估仍需另行准备数据集、模型文件及 Python 环境。
